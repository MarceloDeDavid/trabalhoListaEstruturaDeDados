## Trabalho: Lista (Estrutura de Dados)

Este repositório contém a implementação de uma estrutura de dados do tipo Lista desenvolvida na linguagem C.

## O projeto é composto pelos seguintes arquivos principais:

- lista.h: Arquivo de cabeçalho (Header). Contém a definição das estruturas de dados (structs) e as assinaturas (protótipos) de todas as funções que manipulam a lista.

- lista.c: Arquivo de implementação. Contém a lógica detalhada de cada função declarada no .h (ex: criar lista, inserir elemento, remover elemento, buscar, etc.).

- main.c: Arquivo principal do programa. Serve para testar a estrutura de dados, instanciando a lista e realizando chamadas às suas funções para validar o comportamento.

## Como Compilar e Executar
Recomendação: onlinegdb.com
